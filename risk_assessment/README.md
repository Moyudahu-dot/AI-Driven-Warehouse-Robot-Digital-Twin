# 风险评估模块与接口协议

## 职责确认

根据《项目信息》 第 8 至 10 节，C 是风险决策与系统集成负责人，负责统一模块协议、计算未来碰撞风险、实现减速和等待策略、对接预测与导航、完成系统级对照实验及可视化，并撰写风险算法、总体架构和系统实验分析；A 负责仿真与导航环境，B 负责数据与预测模型，C 不承担从零搭建仿真或训练 GRU 的主要责任。

第一周范围是统一接口和基础风险计算，本目录完成接口提案、算法实现与模拟输入验收，不将第二周的控制策略、第三周的实机仿真闭环或第四周的对照实验冒充已完成。协议尚需 A、B 确认，当前没有访问 GPU 虚拟机或执行 Isaac Sim/Nav2 联调。

## 运行方法

要求 Python 3.10 或更高，无第三方依赖，在本目录运行：

```powershell
python demo.py
python -m unittest -v
python demo.py --input input_example.json
```

`risk.evaluate(payload)` 是供集成调用的入口，`demo.py` 是 JSON 输入输出适配器，`test_risk.py` 是算法验收测试；这些程序均不会向机器人发送指令。

## 接口协议版本 1.0

统一使用 `map` 二维坐标系、米、秒与米每秒，所有时间均为同一仿真时钟的绝对秒数，不混用系统时钟；仿真重置后清空历史与旧预测。建议采样 10 Hz、预测未来 2 秒，但风险模块支持不等间隔时间点，要求轨迹完整覆盖评估区间。示例采用两个端点验证连续计算，正式预测可使用当前点和未来 20 点。

| 字段 | 含义与约束 |
| --- | --- |
| schema_version / frame_id | 固定为字符串 1.0 / map |
| stamp / horizon_s | 本轮评估起点与正数预测时长 |
| safety_margin_m | 非负表面安全余量，初始试验值 0.3 m |
| max_observation_age_s | 最大观测年龄，初始试验值 0.2 s |
| robot.id / radius_m | 机器人稳定 ID 与大于零的保守外接圆半径 |
| robot.trajectory | 机器人预计时间轨迹，每点为 t、x、y |
| obstacles | 显式障碍物列表，空列表表示上游明确报告无障碍物 |
| obstacles[].id / radius_m | 唯一非空障碍物 ID 与保守外接圆半径 |
| obstacles[].observed_at | 最新有效观测时间，不得晚于 stamp 或超过允许年龄 |
| obstacles[].trajectory | 与机器人同一坐标系、同一仿真时钟的预测轨迹 |

完整机器可读输入见 `input_example.json`。位置和时间必须是有限数值，时间严格递增；不完整覆盖、旧观测、重复 ID 或缺失字段返回 UNKNOWN，调用方不得把 UNKNOWN 当作安全。

A 向集成层提供 stamp、frame_id、机器人位置与朝向、二维速度、规划路径、尺寸及障碍物 ID、位置、速度、历史观测时间和尺寸；规划路径本身不含到达时间，集成层必须通过规划速度生成机器人时间轨迹，第一周可以用当前位置与速度进行匀速外推并标明此假设，不能把路径点序号当时间。

B 向集成层提供每个障碍物的 ID、observed_at、预测点绝对时间及二维坐标、model_name 和 inference_ms，建议历史窗口 20 点、未来窗口 20 点；若模型输出相对未来时间，集成层须加上该次预测的基准仿真时间，并补入当前观测点后再调用风险模块，尺寸从 A 的对象登记表按 ID 连接。无法覆盖当前评估区间时请求重新预测，不自动外推缺失部分。

C 输出 status（CLEAR、RISK、UNKNOWN）、全局 min_clearance_m、first_buffer_entry_s，以及各障碍物的最小表面间距、达到最小间距的相对秒数、安全缓冲区首次进入秒数和 predicted_contact；没有障碍物或没有缓冲区进入事件时相应数值为 null，不使用 Infinity。CLEAR 仅表示给定预测窗口内未发现风险，不构成实际行驶安全保证。

后续 C → A 的动作协议建议为 NORMAL、LIMIT_SPEED、PAUSE、RESUME、REQUEST_REPLAN，附带仿真时间、有效期、限速值、风险对象 ID 和原因；具体 ROS 2 消息类型与 Nav2 接口在 A 验证环境后确定，本周不绑定未经验证的消息类型，也不提前将二级风险状态转换成控制命令。

## 基础风险算法

将机器人和障碍物保守近似为圆，中心距离减去双方半径得到表面间距，负值表示预测形状重叠；将双方轨迹的时间节点合并，对每段做线性插值，使比较发生在同一仿真时刻。

每一段内相对位置为 q + vτ，最近时刻为 clamp(−q·v / (v·v), 0, Δt)，相对速度为零时取段起点；遍历所有段得到窗口最小间距，并解 |q + vτ|² = (机器人半径 + 障碍物半径 + 安全余量)²，取最早进入缓冲区的时刻。这样可识别两个采样点之间发生的交叉碰撞，避免仅检查离散位置漏检。

RISK 表示窗口内进入安全缓冲区，CLEAR 表示没有进入，UNKNOWN 表示无法可靠计算；这只是第一周风险结果，第二周再加入分级阈值、减速与等待、恢复滞回和指令有效期。初始尺寸、余量与观测年龄均是模拟验收参数，须根据 A 提供的实际模型、制动能力和延迟重新设定。

## 验收与限制

迎面示例中机器人从 (0,0) 到 (2,0)，障碍物从 (2,0) 到 (0,0)，时长均为 2 秒、半径均为 0.3 m、安全余量 0.3 m，因此预期最小表面间距为 −0.6 m，最近时刻为 1 秒，首次进入缓冲区为 0.55 秒，结果为 RISK。

自动测试覆盖迎面采样间碰撞、横穿、远离通行、静止重叠、不同采样网格、空对象列表、非法或过期输入及重复 ID，运行结果见 `verification.txt`；这是确定性几何验收，不是模型效果或系统导航实验，不得将其用于宣称 GRU 改善成功率。

目前模型只考虑平面圆形包络和分段线性预测，没有建模预测不确定性、机器人制动距离、静态障碍或传感器漏检，Nav2 原生避障仍须保留；空对象列表只在上游成功完成观测时有效，上游失联必须通过错误状态或超时处理，不得伪装为空列表。
